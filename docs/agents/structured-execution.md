# 结构化执行补充

适用：GPT-5.6 Sol、Terra、Luna、其他非 Astra 或型号不明的执行者。已确认的 GPT-6 Astra 只在任务需要或用户指定时参考。它增加执行提示，不改变 [AGENTS](../../AGENTS.md)/[验证策略](../VERIFICATION.md) 的权限、必跑范围与完成标准。

1. 确认任务与完成标准、允许修改范围、当前工作区已有改动。没有清晰规格时先查用户请求、TODO 和现有契约，不自行扩大任务。
2. 按 [AGENTS](../../AGENTS.md) 的文档路由读取相关章节。主代理已提供精确章节和仍有效证据时直接使用；遇到新增影响面再补读，不通读无关资料。
3. 实现前简述本次要改变的行为、可能破坏的具体路径和最小检查。定位根因不必先制造自动化复现；原因假设必须与已经观察的事实分开。
4. 实施小而完整的修改。涉及 IPC/Schema/错误语义时使用项目同步清单；不新增未批准依赖、不预建冻结能力、不重构无关代码。
5. 对修复先记录用户原症状与可用复现证据。高价值行为有合适测试入口时按验证策略做红绿；没有适合的自动入口则记录实际路径与证据缺口，不用浅层 mock 冒充原症状验证。
6. 执行 [验证策略](../VERIFICATION.md) 对该影响面规定的检查。失败先判断是否由本次变更引起；修复后重跑受影响项。不能用全量测试、更多设备或新增报告代替定位。
7. 核对最终差异：是否有无关文件、遗留诊断、故意注入、契约遗漏或未解决的相关失败。保留用户原有改动，清除本次临时缺陷。
8. 交回实际修改、检查结果、复用证据、未测范围和需要主代理决定的问题。实现完成与阶段验收分别记录；不自动提交或推送。

发现任务契约无法判定、检查仍失败或所需改动超出派工范围时，向主代理返回事实与最小待决定项。主代理决定补充资料、缩小任务或升级模型。不能擅自改换 provider 或降低标准。

本文件是普通项目参考文件；即使宿主没有全局配置或未加载全局结构化补充，所有非 Astra 或型号不明的执行者仍必须按上述检查点执行。它们独立作为主代理启动时，也执行本补充；没有主代理可以询问时，只有确需用户决定的事项才询问，其余已授权工作继续推进。

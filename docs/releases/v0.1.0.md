# EpubStart v0.1.0

EpubStart 的第一个发行版：本地 EPUB 导入、书架与阅读，面向 Windows x64 和 Android arm64，采用 GPL-3.0 开源协议。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `EpubStart-0.1.0-windows-x64.zip` | Windows 免安装版；完整解压后运行 EpubStart.exe，需要 WebView2 Runtime |
| `EpubStart-0.1.0-android-arm64.apk` | Android arm64 安装包，使用专用正式签名 |
| `EpubStart-0.1.0-source.zip` | 此版本的项目源码与构建说明 |
| `EpubStart-0.1.0-licenses.zip` | GPL 与完整第三方声明 |
| `EpubStart-0.1.0-third-party-sources.zip` | 对应第三方源码与来源清单 |
| `SHA256SUMS.txt`、`build-manifest.json` | 下载校验、版本、提交号与构建信息 |

Windows EXE 未做 Authenticode 签名，系统可能显示发布者未知。Android 与早期 debug/profile 安装使用不同签名；已有测试版发生安装冲突时，请保留数据并联系维护者。此版本不提供 Linux、iOS、32 位 Android 或应用商店安装。

## 这一版

- 本地 EPUB 导入、封面书架、正文阅读、目录、搜索和阅读设置。
- 高亮批注、系列、标签和本地阅读记录等已实现功能。
- 修复模式切换白屏、分页列距、快速开关书回调冲突和窄屏/横屏工具栏布局。
- 首版验收重点为正常导入，以及在用户选定的排版下连续阅读。

## 已知限制与验证范围

- 改字号、阅读模式、窗口或方向后，阅读位置可能变化；Android 横屏重启存在位置回退情况。
- Android 暂不支持书内图片导出。TXT、PDF、漫画压缩包和跨设备同步尚不支持。
- 未逐页验证所有书籍；固定/混合版式、旧 Android、全部附加功能和性能耗电没有完成统一全矩阵。
- 复用已验收业务代码的 Reader 65/65、相关 Windows/Android 15 实机记录与构建检查。最终 APK 的签名、对齐、版本和体积已核对，原有 921 个载荷文件逐字节一致，仅附许可文本与签名信息。按维护者决定，本次未追加最终分发包的设备安装/启动测试。

项目采用 **GNU GPL v3.0 only**（GPL-3.0-only），允许按协议商用、修改和再分发；第三方保留原有许可。对应源码随本 Release 提供，构建说明位于源码的 `docs/releases/BUILDING-v0.1.0.md`。

# EpubStart v0.1.0 首版说明（发布准备中）

状态：业务验收按维护者确认的首版范围收尾；尚未正式发布。项目许可证和正式 Android 签名待定。

## 首版范围

Windows x64 与 Android arm64，本地 EPUB 导入与阅读。核心目标是在读者选定的排版下正常连续阅读。提供书架、目录、搜索、阅读设置、高亮批注，以及系列、标签和阅读记录等已实现功能；不同附加功能的实机验证覆盖有差异。

## 本轮修复

- 阅读模式切换期间的白屏，以及分页列距不一致导致的跨页问题。
- 快速关闭、切换书籍时的异步回调和销毁冲突。
- 小窗口及 Android 横竖屏下的工具栏布局。
- 阅读状态、设置和保存请求的顺序与过期结果隔离。
- 移除 WebView 不需要的 XML 兼容实现，降低前端资源体积。

业务源码提交：`1a9175728c1b478e831ddebf3bca0a0ea3098bc7`，对应验收候选 `20260916-dual-fix-2`。发布说明与许可文件的后续提交不改变这份业务源码。

## 保留的限制

1. 改字号、阅读模式、窗口或屏幕方向后，阅读位置可能变化；Android 横屏重启存在位置回退的已知情况。精确保位与 Reader 重构后置。
2. Android 图片导出尚不支持。
3. 未逐页走完全部书籍；固定或混合版式、旧 Android、全部附加功能及性能耗电未完成统一全矩阵。
4. Linux、iOS、TXT、PDF、漫画压缩包及跨设备同步不属于本次发行。

- `list_book_tags` 返回的 `inherited_from_series` 项仅展示为系列继承并禁用编辑；`set_book_tags` 只提交直接标签 ID。
- 系列标签使用 `list_series_tags` / `set_series_tags`；标签筛选在选中至少一个标签时调用 `filter_books_by_tags`，直接消费后端返回结果；清空筛选恢复页面收到的书架列表且不提交空筛选请求。

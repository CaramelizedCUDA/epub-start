# Agent 规范按任务与模型分层

日期：2026-09-12。范围：项目 Agent 入口、文档阅读路由、模型委派与结构化执行补充。用户已授权沿用当前分支修改、提交和推送；本机全局规范与 skills 仅另行保留本机备份和变更存档。

## 改动与影响

- [AGENTS](../../AGENTS.md) 改为按当前影响面阅读契约，取消首次进入必须通读全部文档的流程。
- 已确认的 GPT-6 Astra 按任务选择方法；所有非 Astra 或身份不明的执行者必须读取 [结构化执行补充](../agents/structured-execution.md)，包括独立主代理和子代理。
- [模型路由](../agents/model-routing.md) 取消固定的 Astra/Luna max 分工。先判断是否值得委派，再按任务、宿主支持和用户选择确定模型与推理等级；候选表不是模型性能基准。
- 各模型的产品契约、权限、依赖白名单、冻结范围、IPC/Schema 同步、数据保护、验证矩阵和停止条件保持一致。
- TODO、CONVENTIONS 和文档索引同步入口。没有修改产品实现、任务完成状态、设备验收结论或历史统计。

这类变更可能通过错误的文档路由遗漏契约、让子代理错误继承精简流程，或把模型偏好变成固定门禁。因此本次检查集中于这些路径。

## 实际检查

| 检查 | 结果与证据范围 |
| --- | --- |
| 项目差异、相关 Markdown 链接与状态一致性 | 通过；TODO 入口之后的内容保持原样；验证策略仅替换末尾固定角色句，全部矩阵和红绿要求保持原样 |
| Git 范围 | 仅提交本次文档；保留开始时已有的生成文件和未跟踪设计、Android 资产 |
| 独立 Astra high 文档复核 | 项目与全局共同约束、三项核心 skill 无关键发现；发现本机设计参考中旧测试删除条件过宽及部分技能的其他非 Astra 分支遗漏，均已修正并定点核对 |
| Terra medium 隔离审阅行为 | 读取 code-review 的结构化参考与项目结构化补充，识别暂存缺陷被未暂存修正掩盖，以及未跟踪文件中的错误；未修改 fixture |
| 本机 skills 与配置检查 | 16 项入口、相关引用、YAML 策略、4 份 CLI profile 的 TOML 和输入装配检查完成；完整逐项结果与兼容字段说明保存在本机存档 |

行为样例中的规则为“18 岁及以上可用”和“返回打九折后的价格”。审阅者发现暂存版本把 `>= 18` 改成 `> 18`，即使最终工作区无 HEAD 差异也没有漏报；另发现新文件返回折扣额而非折后价。此证据支持该次指定 Terra 执行的阅读与审阅行为，不代表所有模型的自动选 skill 或真实供应商兼容性。

## 未覆盖与生效边界

- 本次为文档与本机规则修改，依 [验证策略](../VERIFICATION.md) 不构建应用、不重跑设备测试或 Rust 统计。
- 已有会话中读入的旧规则不会因文件变更而从上下文消失。CLI 输入装配证据不代表桌面热重载或实际供应商推理测试。
- 外部 agent 必须由其宿主加载相关入口与结构化补充；没有把 DeepSeek 等型号声明为当前可用工具，也没有切换供应商。
- 本机备份、skills、profile 和隔离样例不随项目仓库上传。项目结构化补充可独立使用，不依赖特定个人磁盘路径。

设计依据为 OpenAI 的 [Rethinking skills and prompts for GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra) 中按能力调整约束、保留有效专业知识与通过行为验证改动的思路；本仓库的候选路由属于本地执行策略。
